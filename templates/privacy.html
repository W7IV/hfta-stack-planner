Privacy

What this public copy of HFTA Stack Planner keeps, for how long, and where data goes. It is run by {{ public.operator }}{% if public.contact %} ({{ public.contact }}){% endif %}.

What the server keeps

  • A random workspace number, in one cookie in your browser. The cookie is signed. It is needed to find your workspace. It is not used to track you.
  • What you enter or make in your workspace: project names, site positions, notes, antennas, terrain profiles, the elevation-angle files you add or generate, and calculation results.
  • There is no account. The server does not ask for or keep your name, e-mail address or password.
  • No scripts from other websites run on these pages.

How long it is kept

  • A workspace that is not used for {{ public.expiry_days }} days is deleted, with everything in it. This cannot be undone.
  • You can delete a project earlier (Report page, Delete project).
  • If you clear your browser's cookies, you lose access to your workspace. It stays on the server until it expires.
  • To keep your work, export the project zip (Report page) and open it again later.
  • Each workspace may hold up to {{ public.workspace_mb }} MB.

Where data goes

  • Terrain. Only when you click "Fetch terrain online", the site position is sent to USGS (3DEP) or to Amazon's Terrain Tiles service. They also see the address of this server, not yours. The elevation tiles are kept on the server for all visitors. They are public data and are not linked to you.
  • Map. When you open "Pick location on map", your browser loads map tiles directly from OpenStreetMap. OpenStreetMap can see the area you view and your IP address. Do not open the map if you do not want to share a confidential station position this way.
  • Access log. The hosting service (Railway) keeps a web access log with addresses, paths and times. It does not record the contents of your requests.

Usage counts

{% if public.usage_counts %}

The server keeps daily totals of use: how many workspaces were made and used, how many calculations and terrain fetches ran, and how often a limit was reached. The totals hold no personal data, no address and no workspace number. Only the operator can see them. No outside analytics service is used.

{% else %}

The server does not run any analytics.

{% endif %}

ARRL files

{% if public.prn_upload %}

ARRL elevation-angle (.PRN) files are copyright ARRL. If you upload one, upload only a file you are entitled to use. It stays in your private workspace. It is never shared or listed, and it is deleted with the workspace.

{% else %}

This public copy does not accept ARRL elevation-angle (.PRN) files. Make a table with VOACAP instead.

{% endif %}
